#+TITLE: tikzcd snippets for VS Code

For writing LaTeX documents, I use(d to use) [[https://code.visualstudio.com/][VS Code]] together with the [[https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop][=latex-workshop=]] extension.

One thing I particularly like about VS Code is its built-in support for [[https://code.visualstudio.com/docs/editor/userdefinedsnippets][snippets]] and how easy it is to implement your own.

As there aren't any extensions in the [[https://marketplace.visualstudio.com/vscode][marketplace]] providing snippets for commutative diagrams, I implemented some using =tikz-cd= on my own:

# [=snippets-tikzcd=](https://marketplace.visualstudio.com/items?itemName=tholzschuh.snippets-tikzcd)

In case you want to try it for yourself, I packaged the whole thing and published it as the [[https://marketplace.visualstudio.com/items?itemName=tholzschuh.snippets-tikzcd][=snippets-tikzcd=]] extension.

To install the extension, simply go to =File ⟶ Preferences ⟶ Extensions=, search for =snippets-tikzcd= and install.
If you for some reason dislike using the marketplace, you can also find the plugin in the =versions= folder of [[https://github.com/tholzschuh/snippets-tikzcd][this]] GitHub repository.

## supported diagrams

Here's the kinds of diagrams the extension currently supports:

- (pushout/pullback) =square=
- =triangle=
- =cube=
- (short/split/long) exact =sequence= and the =snake=
- equalizers and reflexive parallel =pair=
- (augmented) (co-)​=simplicial= objects
- =adjunction= and natural =transformation=

Read the above as =trigger= triggers the drop-down menu to select all the varieties of diagrams of shape =trigger= (as in the demo).

Note that, in the future, the above list might not be comprehensive anymore if I end up adding some other diagrams.
I'll try to always keep the information on the [[https://marketplace.visualstudio.com/items?itemName=tholzschuh.snippets-tikzcd][overview page]] of the extension up-to-date.

## contributing

If you'd like to have other types of diagrams supported or have anything else to report, either contact me or submit a pull request at the GitHub [[https://github.com/tholzschuh/snippets-tikzcd][repo]].
